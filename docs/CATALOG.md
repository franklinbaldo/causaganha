# CausaGanha catalog

The public catalog is a **reconstructible SQL contract over public Parquet files**.
It is intentionally not distributed as a canonical `.duckdb` database file.

The Internet Archive item `causaganha-catalog` publishes:

- `catalog.sql` — DuckDB SQL that creates the remote views used by the catalog;
- `manifest.parquet` — index of archived files;
- `backfill-needed.parquet` — known DJEN gaps that still need collection/backfill;
- progress JSON/JSONL artifacts generated by the catalog pipeline.

The underlying court/year Parquet files remain in their canonical `djen-{tribunal}-{year}` Internet Archive items. `catalog.sql` points DuckDB at those public artifacts, so each consumer can create its own local database without downloading a project-owned binary database.

## Rebuild locally

With DuckDB installed:

```sh
curl -L https://archive.org/download/causaganha-catalog/catalog.sql -o catalog.sql
duckdb causaganha.duckdb < catalog.sql
duckdb causaganha.duckdb "SELECT * FROM comunicacoes LIMIT 100;"
```

The first command fetches the text contract. The second applies it to a DuckDB file owned by the consumer. The third is only an example query; the views themselves continue reading the canonical public Parquets.

For a single Parquet file, a catalog is not required:

```sql
SELECT *
FROM read_parquet('https://archive.org/download/djen-tjro-2025/comunicacoes.parquet')
LIMIT 100;
```

## Why text instead of a published DuckDB binary?

`catalog.sql` is inspectable, diffable and reproducible. The durable public data are the archived source ZIPs, Parquets, manifests and the SQL required to project them into a queryable catalog. A `.duckdb` file may still be generated transiently inside the pipeline for validation, but it is not part of the public distribution contract.
