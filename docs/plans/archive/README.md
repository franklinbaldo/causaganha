# Archived Plans

This directory contains plans that were created for v1 but are no longer relevant for v2 development.

## Why These Are Archived

CausaGanha v2 represents a fundamental architectural shift:
- **FROM**: Web scraping diários with pandas-based analytics
- **TO**: PJe API integration with Ibis-based analytics

Many v1 plans focused on improving the scraping infrastructure or pandas-based operations, which are being replaced entirely in v2.

## Archived Plan Categories

1. **Web Scraping Improvements**: Plans to improve scraping reliability (obsolete - using API now)
2. **Pandas Optimizations**: Plans to optimize pandas operations (obsolete - using Ibis now)
3. **Diário-Specific Features**: Plans focused on diário PDF processing that won't apply to API-based metadata

## Active Plans

See `/docs/plans/` for plans that remain relevant:
- MASTERPLAN.md - Overall coordination (updated for v2)
- Plans that focus on OpenSkill, database architecture, or general system features

## Reference Value

These archived plans are kept for:
- Historical context
- Understanding v1 design decisions
- Lessons learned for future features
- Potential ideas that might apply to v2 in different form
