# Goal: IA_UPLOAD_RATE_LIMIT nunca deve produzir um AsyncLimiter quebrado

`_ia_max_rate` só tratava `ValueError` (string não numérica). Um valor numericamente válido mas não positivo (`"0"` ou negativo) passava direto para `AsyncLimiter(max_rate=...)`, cujo `.acquire()` levanta `ValueError` sempre que `max_rate <= 0` -- exceção que nenhuma camada da cadeia de chamadas (`upload_zip`, `_process_upload_item`, `upload_worker`) captura.
