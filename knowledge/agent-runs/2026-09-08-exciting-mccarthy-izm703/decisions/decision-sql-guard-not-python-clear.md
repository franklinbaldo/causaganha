# Decisão: corrigir nas .qmd, não limpar djen_status no runtime

O codebase já resolve esta mesma ambiguidade em três lugares (`_categorize()`, o compactor de deltas, `tribunal_calendar.qmd`): `uploaded` vence sobre `absent` obsoleto. A correção mínima e já precedente é replicar essa mesma guarda (`AND ia_status != 'uploaded'`) nos filtros `absent` de `totals.qmd`, `tribunal_coverage.qmd` e `court_reliability.qmd` -- exatamente a guarda que os filtros `pending`/`unknown` desses mesmos arquivos já têm. Alterar `mark_ia_uploaded()` no runtime seria mais arriscado (mexe no cache incremental de contagens) para o mesmo resultado observável, e apagaria o histórico do último `djen_status` real sem benefício de relatório adicional.
