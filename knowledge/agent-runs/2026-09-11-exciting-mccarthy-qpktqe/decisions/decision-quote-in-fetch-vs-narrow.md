# Decisão: quote() em fetch_juris_from_ia, não uma comparação tolerante em _narrow_juris_datasets_for_cnj

Corrigido no lado que constrói a URL armazenada (`fetch_juris_from_ia`), não no lado que compara (`_narrow_juris_datasets_for_cnj`). `published._juris_url` já é a autoridade única e testada para essa política de codificação; alinhar `fetch_juris_from_ia` a ela mantém o invariante centralizado, em vez de espalhar normalização em cada ponto de comparação futuro. Também é o lado tecnicamente correto: o próprio `httpx` já envia a requisição HTTP com o nome codificado -- a string crua armazenada já contradizia a própria intenção documentada de "ground truth: literalmente de onde os bytes vieram".
