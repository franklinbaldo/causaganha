# Goal: corrigir o mismatch de percent-encoding nas URLs JURIS

`fetch_juris_from_ia` armazenava o nome de arquivo bruto (não codificado) do item IA como `arquivo_ia_url` no índice, enquanto `causaganha.decisoes.published._juris_url` sempre calcula a URL com `quote()`. `_narrow_juris_datasets_for_cnj` compara essas duas URLs por igualdade estrita de string para decidir quais datasets JURIS pertencem a um CNJ -- como todo `tipo` real do TJRO (ACÓRDÃO, SENTENÇA, DECISÃO, DECISÃO DA PRESIDÊNCIA) tem acentuação, as duas strings nunca batem para nenhum shard real, e `decisoes_buscar` retorna silenciosamente zero resultados JURIS para praticamente qualquer CNJ real com decisão JURIS. Corrigido aplicando `quote()` também em `fetch_juris_from_ia`. Achado por auditoria profunda de um agente Explore dispachado após o goal original desta rodada ter sido completado por uma sessão concorrente antes da própria PR desta rodada mesclar.
