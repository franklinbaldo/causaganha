# Goal: totals.qmd coverage_pct nulo, não NaN, quando o manifest está vazio

`totals.qmd` era a única fonte de `coverage_pct` sem proteção contra divisão por zero -- ao contrário de `site_status.qmd` (mesmo arquivo de queries) e `court_reliability.qmd`, que já guardam esse caso. Com manifest vazio, DuckDB produz `NaN`, um token JSON inválido que quebra o `JSON.parse` estrito do frontend e falha o build inteiro (`totals.qmd` não é `optional`). Corrigido com `NULLIF(COUNT(*), 0)`, igual ao padrão já usado por `site_status.qmd`.
