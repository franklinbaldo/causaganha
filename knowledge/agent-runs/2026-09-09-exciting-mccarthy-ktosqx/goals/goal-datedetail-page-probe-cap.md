# Goal: DateDetail descobre todas as páginas, não só as 30 primeiras

`DateDetail.svelte` sondava a existência de shards JSON com um array fixo de 30 posições -- qualquer par (tribunal, data) com mais de 30.000 publicações (30 páginas de 1000) nunca teria suas páginas 31+ descobertas, cortando silenciosamente "carregar mais", links profundos além do seq 30000, e o rótulo de "X páginas" no cabeçalho. Corrigido trocando o array fixo por uma sondagem em lotes crescentes de 30, que só para quando um lote inteiro vem sem nenhuma página válida.
