# Decisão: não adicionar `Fonte: tcu` ao modelo OKF

`fonte="tcu"` já existe em `decisoes_buscar`, mas o slice OKF `Fonte`/`Pipeline` está deliberadamente restrito aos quatro motores de sincronização contínuos com cron/workflow/status. TCU é uma publicação em lote anual sem nenhum desses três, e não existe hoje uma tabela de alias entre os códigos curtos de `decisoes_buscar` (`juris`/`stj`/`tcu`) e os nomes de módulo de `Fonte` (`tjro_juris`/`stj_acordaos`) nem para as duas fontes que já se sobrepõem. Adicionar uma linha `Fonte` avulsa seria decorativo, não uma correção real — deixado como possível trabalho futuro explícito, não como fix oportunista desta rodada.
