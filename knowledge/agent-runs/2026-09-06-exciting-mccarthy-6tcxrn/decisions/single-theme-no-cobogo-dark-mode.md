# Decisão: tema único, sem paridade Cobogó para modo escuro

O preset compartilhado `cobogo` (pacote externo, fora do escopo de acesso GitHub desta sessão) não define nenhum mecanismo de modo escuro — nem condições Panda, nem variante de semantic token, nem `data-theme`. Reconstruir isso localmente contrariaria a orientação do próprio skill do Cobogó (preferir token/recipe compartilhado a equivalente local) e recriaria o mesmo problema da issue com código novo. Optou-se por remover o componente órfão e proteger a decisão com um teste de regressão.
