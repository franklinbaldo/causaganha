# Decisão: contrato de ordem no source, sem harness Astro novo

Sem `astro/container` já usado no repo e com o frontmatter de `/publicacoes` dependendo de um artefato só disponível em build real, um teste de ordem de marcadores no texto-fonte do `.astro` é o menor RED→GREEN fiel possível — evita criar infraestrutura de teste nova para uma mudança de composição de uma única página, seguindo o mesmo padrão de validação (captura visual, sem harness de render) já aceito pela própria issue em `/processo` (#1151).
