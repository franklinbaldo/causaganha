# Decisão: prefixo underscore para excluir o teste do roteamento Astro

O `compare-product-surfaces` da PR #1160 falhou porque o Astro trata qualquer `.ts` sob `web/src/pages/` (recursivamente) como rota roteável, inclusive o teste Vitest colocado nesta rodada. Renomear para `_index.order.test.ts` usa o mecanismo oficial do próprio Astro (confirmado no código-fonte de `create-manifest.js`) para excluir arquivos de `src/pages/` do roteamento, mantendo o teste colocado ao lado da página que ele testa. Validado com `npx astro build` real (109 páginas, sem a rota espúria) usando os fixtures de `scripts/render_contract_fixture.py` para suprir a dependência de `site-status.json` que este sandbox não tem localmente sem rede.
