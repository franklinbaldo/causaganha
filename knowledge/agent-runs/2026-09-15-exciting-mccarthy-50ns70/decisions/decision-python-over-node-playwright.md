# Decisão: portar o probe de CORS para Python em vez de consertar o `.mjs` no lugar

`playwright` já é dependência Python declarada (`pyproject.toml`, grupo `dev`) mas não usada em lugar nenhum do repositório. Reescrever o probe em Python reaproveita essa dependência já existente, evita criar uma nova superfície de gerenciamento de pacotes Node (nenhum `package.json` raiz existe hoje) e mantém o repositório consistente com seu próprio padrão Python-first. `wasm_query_bench.mjs`, irmão do script corrigido aqui, tem o mesmo bug de caminho hardcoded mas pertence a outra issue (#1471) e não foi tocado nesta rodada para evitar scope creep.
