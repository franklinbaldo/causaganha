# Goal: corrigir inflação de completude por fins de semana

`SyncManifest.build()` so cria linhas para dias uteis; sabado/domingo nunca existem no manifesto. Mas `TribunalDetail.svelte` e `velocityCalc.ts` contavam todo dia de calendario como "esperado", limitando a completude a ~71% para qualquer tribunal, por mais em dia que estivesse, e disparando cartoes de "anomalia" falsos permanentemente. Corrigido para contar apenas dias uteis, com testes novos cobrindo as funcoes puras (`dateUtils`, `velocityCalc`) e o componente (`TribunalDetail`).
