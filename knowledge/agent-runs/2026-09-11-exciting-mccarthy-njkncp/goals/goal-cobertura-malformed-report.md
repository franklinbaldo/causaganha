# Goal: cobertura report malformed-shape resilience

`_carregar_cobertura` deve degradar (não lançar) quando `indice_processual.report.json` é sintaticamente válido mas tem forma errada. Um campo (`status`/`rows`) ausente ou mal-tipado dentro de uma entrada de fonte que é um dict degrada por-campo, igual ao gêmeo TypeScript `fetchCobertura`. Um `sources` que não é um dict (achado depois, na revisão da PR #1454) não tem entradas de fonte para degradar por-campo, então segue o caminho de relatório indisponível.
