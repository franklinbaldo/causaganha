## Summary
Implement the `PJeAPIClient` as the first step in building the V2 data ingestion pipeline. This client is critical for fetching structured data from the PJe Communications API, which is the cornerstone of the V2 architecture.

## Acceptance criteria (BDD)
```gherkin
Feature: PJe API Client Implementation
  As a data engineer
  I want a robust API client for the PJe Communications API
  So that I can reliably fetch structured judicial data.

  Scenario: Fetching intimations successfully
    Given a PJeAPIClient instance
    When I call `get_intimations_by_court` for a valid court and date range
    Then the client should return a list of `Intimation` objects
    And the response should be validated against the Pydantic model.

  Scenario: Handling API errors gracefully
    Given a PJeAPIClient instance
    When I call `get_intimations_by_court` and the API returns an error
    Then the client should raise an appropriate HTTP exception.

  Scenario: Automatic pagination
    Given a PJeAPIClient instance
    When I call `get_intimations_by_court` for a query that spans multiple pages
    Then the client should handle pagination automatically
    And return a complete list of all intimations.
```

## Constraints / Non-goals
- This task is only for the API client. Do not implement the full data pipeline.
- Do not implement the database storage layer yet.
- Focus on the `httpx` implementation as specified in the V2 plan.

## Requested actions
1. Create a new file `src/causaganha/clients/pje.py`.
2. Implement the `PJeAPIClient` class in that file, following the detailed implementation provided in `causaganha-v2-plan-from-scratch.md`. This includes the Pydantic models for API responses.
3. Add unit tests for the client in a new file `tests/clients/test_pje.py`. Ensure the tests cover success, error, and pagination scenarios.

## Definition of done
- `src/causaganha/clients/pje.py` exists and contains the complete `PJeAPIClient` and Pydantic models.
- `tests/clients/test_pje.py` exists and contains comprehensive unit tests.
- All new tests pass when running `uv run pytest`.
