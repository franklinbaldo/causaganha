## Summary
RE-FORWARDING: The current CLI implementation in `src/causaganha/cli/__init__.py` is a monolith containing nearly 1,200 lines of code and many diverse command groups. This "God File" makes the codebase harder to maintain and contributes to slower startup times. This brief initiates the decomposition of the CLI by extracting the `catalog` command group into a separate submodule.

## Acceptance criteria (BDD)
- **Given** the `catalog` commands are currently in `src/causaganha/cli/__init__.py`,
- **When** I move them to `src/causaganha/cli/commands/catalog.py`,
- **And** I register the `catalog_app` in `src/causaganha/cli/__init__.py`,
- **Then** `causaganha catalog --help` should still function identically to the current implementation.
- **And** all BDD tests for the catalog system should continue to pass.

## Constraints / Non-goals
- Do not change the behavior or parameters of the catalog commands. This is a pure refactor.
- Do not attempt to decompose other command groups (e.g., `analyze`, `score`) in this task.

## Requested actions
1. **Create Submodule:**
   Create the directory `src/causaganha/cli/commands/` if it doesn't exist (with `__init__.py`).
2. **Extract Logic:**
   Move all logic related to `catalog_app` from `src/causaganha/cli/__init__.py` to `src/causaganha/cli/commands/catalog.py`. This includes the `@catalog_app.command()` functions and any specific helper functions they use (e.g., `_validate_tribunal_code`, `_validate_parquet_schema`).
3. **Refactor Entry Point:**
   Update `src/causaganha/cli/__init__.py` to import `catalog_app` from the new submodule and add it to the main `app` using `app.add_typer(catalog_app, name="catalog")`.
4. **Clean up Imports:**
   Ensure that `src/causaganha/cli/__init__.py` no longer imports modules that are only needed by the catalog commands.

## Definition of done
- The `catalog` command group is successfully moved to `src/causaganha/cli/commands/catalog.py`.
- `causaganha catalog --help` works correctly.
- All catalog BDD tests pass.
- `src/causaganha/cli/__init__.py` is significantly smaller.
