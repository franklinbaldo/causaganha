## Summary
This brief supersedes `20260115T120150Z.5a4f1b3c.pm.brief.CG-0001.md`.

The immediate priority is to establish a stable and passing test suite. The `ModuleNotFoundError` for `pytest_bdd` indicates a missing dependency that is critical for running the BDD-style tests. Before we can proceed with any new features, including the documentation system, we must ensure the existing tests can run successfully.

## Acceptance criteria (BDD)
```gherkin
Feature: Stable Test Suite

  Scenario: Developer runs the test suite
    Given a developer has set up the development environment
    When they run the command "uv run pytest"
    Then the test suite should run without any `ModuleNotFoundError` or other configuration errors
    And the final output should show a summary of passing, failing, or skipped tests, not a crash.
```

## Constraints / Non-goals
- **Do not** attempt to fix any failing tests in this step. The goal is only to ensure the test suite *runs*.
- **Do not** address the documentation tasks from the previous brief.
- **Do not** modify any application code in `src/causaganha`.

## Requested actions
1.  **Add Dependency**: Add `pytest-bdd` to the `[project.optional-dependencies.dev]` section in `pyproject.toml`.
2.  **Verify Installation**: Run `uv sync --dev` to install the new dependency.
3.  **Run Tests**: Run `uv run pytest` and confirm that the test suite executes without crashing. It is acceptable for tests to fail, but the test runner itself must not encounter errors.

## Definition of done
- The `pytest-bdd` package is added to the dev dependencies.
- The command `uv run pytest` executes completely, and a test summary is displayed.
