## Summary
This brief is an update to CG-0005. While the `catalog` CLI commands have been mostly implemented in `main`, they are currently unreachable because the application crashes during import. The crash is caused by a `decimal.InvalidOperation` when `ibis` and `sqlglot` interact. A workaround exists in `tests/conftest.py` but must be moved to the core application to restore CLI functionality.

## Acceptance criteria (BDD)
- **Given** the application is installed,
- **When** I run `causaganha --help`,
- **Then** it should execute successfully without an import crash.
- **And** `causaganha catalog --help` should display the subcommands added in recent commits.
- **And** the BDD tests in `tests/step_defs/test_ia_catalog.py` should continue to pass.

## Constraints / Non-goals
- Do not attempt to upgrade `ibis` or `sqlglot` unless the workaround fails.
- Focus on restoring existing functionality before adding new catalog features.

## Requested actions
1. **Move the Workaround:**
   Apply the following fix to `src/causaganha/__init__.py` or another appropriate early-import location:
   ```python
   import decimal
   decimal.getcontext().traps[decimal.InvalidOperation] = False
   ```
2. **Verify Catalog CLI:**
   Confirm that all `catalog` subcommands (`create`, `list`, `info`, `validate`, `download`, `backfill-status`, `query`) are discoverable and that their help text is accurate.
3. **Verify Tests:**
   Run `uv run pytest tests/step_defs/test_ia_catalog.py` to ensure no regressions.

## Definition of done
- The CLI is functional (no crash on import).
- All `catalog` subcommands are present and help text is accessible.
- Acknowledge that the `catalog` implementation is complete according to previous BRIEF requirements.
