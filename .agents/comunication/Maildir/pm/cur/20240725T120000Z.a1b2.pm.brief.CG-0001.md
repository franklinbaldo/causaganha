## Summary

The `causaganha manifest export` command in `src/causaganha/cli.py` is currently broken due to a reference to an undefined `ParquetSchema`. Additionally, the schema is defined directly within the CLI command, which tightly couples the data structure to the command's implementation.

This brief instructs you to fix the bug, refactor the schema into a dedicated module for better separation of concerns, and add a test to ensure the command's functionality and prevent future regressions.

## Acceptance criteria (BDD)

**Given** the `causaganha` CLI is installed
**When** a user runs the command `uv run causaganha manifest export --limit 5`
**Then** the command should execute successfully
**And** it should output a JSON array of 5 intimation metadata objects
**And** each object should conform to the `ParquetSchema` structure.

**Given** the test suite is run
**When** `uv run pytest` is executed
**Then** a new test for the `manifest export` command should pass.

## Constraints / Non-goals

- Do not change the existing CLI command structure (`manifest export`).
- Do not alter the fields in the `ParquetSchema`.
- Non-goal: Do not implement the Parquet export functionality itself. The command should continue to export JSON.

## Requested actions

1.  **Create a new module** `src/causaganha/schemas/manifest.py`.
2.  **Define the `ParquetSchema`** in this new module. The schema should be a Pydantic `BaseModel` with the following fields:
    - `intimation_id`: `int | None`
    - `process_number`: `str | None`
    - `tribunal`: `str | None`
    - `decision_date`: `date | None`
    - `download_url`: `str | None`
    - `needs_download`: `bool | None`
    - `ia_url`: `str | None`
3.  **Import and use the `ParquetSchema`** in `src/causaganha/cli.py` to fix the `NameError`.
4.  **Create a new test file** `tests/cli/test_manifest.py`.
5.  **Write a test** for the `manifest export` command that uses a `CliRunner` to invoke the command and asserts that the output is valid JSON and conforms to the expected schema.

## Definition of done

- The `manifest export` command runs without errors.
- The `ParquetSchema` is defined in `src/causaganha/schemas/manifest.py`.
- A passing test for the `manifest export` command exists in `tests/cli/test_manifest.py`.
- The code adheres to all quality standards defined in `CLAUDE.md`.
