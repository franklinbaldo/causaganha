## Summary
The project's entire test suite is failing to collect due to a `ModuleNotFoundError`. This is a critical blocker. The error is caused by the absence of the `PJeAPIClient` and its associated Pydantic models, which were planned in the V2 refactor but are not present in the current codebase. This brief directs you to recreate these missing files exactly as specified in the project's planning documentation.

## Acceptance criteria (BDD)

**Scenario:** Test suite runs without collection errors
*   **Given**: The project is in its current broken state
*   **When**: The developer creates the file `src/causaganha/api/models.py` with the Pydantic models from the "Implementation Components" section of `causaganha-v2-plan-from-scratch.md`
*   **And**: The developer creates the file `src/causaganha/api/client.py` with the `PJeAPIClient` class from the same document
*   **And**: The developer installs the missing `httpx` dependency by running `uv sync --dev`
*   **And**: The developer installs the project in editable mode with `uv pip install -e .`
*   **And**: The developer executes the test suite command:
    ```bash
    uv run pytest
    ```
*   **Then**: The `pytest` command should execute successfully, collecting all tests without raising a `ModuleNotFoundError`.

## Constraints / Non-goals
- Do not modify any files other than the two new files specified.
- Do not alter the logic of any existing tests. The sole focus is to fix the import paths by creating the missing modules.
- The V2 planning document (`causaganha-v2-plan-from-scratch.md`) is the source of truth for the code to be added.

## Requested actions
1.  Create `src/causaganha/api/models.py` with the Pydantic models (`LawyerInfo`, `DestinarioAdvogado`, `Destinatario`, `Intimation`).
2.  Create `src/causaganha/api/client.py` with the `PJeAPIClient` class.
3.  Ensure the `httpx` dependency is installed via `uv sync --dev`.
4.  Ensure the project is installed in editable mode via `uv pip install -e .`.
5.  Run `uv run pytest` to confirm the fix.

## Definition of done
- The command `uv run pytest` completes its run without any `ModuleNotFoundError` during the collection phase.
